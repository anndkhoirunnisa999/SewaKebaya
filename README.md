# Sewa Kebaya — KebayaRent

KebayaRent merupakan website sistem informasi penyewaan kebaya dan busana untuk berbagai acara, seperti wisuda, lamaran, pernikahan, kondangan, acara adat, dan photoshoot. Website ini dirancang untuk memudahkan pengelolaan koleksi busana, data pelanggan, pemesanan, serta transaksi penyewaan dalam satu sistem yang terintegrasi.

Website ini memiliki beberapa fitur utama, yaitu login admin, dashboard, pengelolaan koleksi kebaya, pengelolaan data customer, pengelolaan booking, dan pengelolaan transaksi pembayaran. Dashboard menampilkan ringkasan jumlah koleksi, customer, booking, dan total pendapatan, serta informasi koleksi dan booking terbaru.

KebayaRent dikembangkan menggunakan PHP sebagai bahasa pemrograman, MySQL sebagai database, HTML dan CSS untuk membangun tampilan website, serta XAMPP sebagai server lokal untuk menjalankan aplikasi.

Website ini diharapkan dapat membantu proses penyewaan kebaya menjadi lebih terorganisasi, efisien, dan mudah dikelola. Selain mengutamakan fungsi, KebayaRent juga mengusung desain yang elegan dengan nuansa warna ivory, beige, dan cokelat untuk memberikan kesan mewah, modern, dan eksklusif seperti butik busana premium.
